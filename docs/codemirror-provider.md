# CodeMirror 6 provider

The editor selector now offers Monaco and a lazy-loaded CodeMirror 6 Vue host. The CodeMirror host uses the same v-model source as Monaco, so switching providers retains the document. It implements the EditorAdapter contract for value, selection, language, diagnostics and focus.

CodeMirror currently supports JavaScript/TypeScript, CSS, JSON, HTML, Markdown, Python and SQL language modes. Other parser languages fall back to plain text. The source editor publishes cursor offsets for AST selection.

## Dependency prerequisite

The main branch package.json does not currently declare the CodeMirror packages, despite the local installation reported. Before merging, commit package.json and the matching pnpm-lock.yaml generated by pnpm add. CI must pass typecheck and generate before deployment.
